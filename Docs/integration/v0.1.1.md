# Integration guide — v0.1.1

Host apps upgrading from `v0.1.0` to `v0.1.1` on iOS (SPM).

## Breaking changes

None for existing integrations. The minimum **deployment target** is lowered from iOS 18 to **iOS 15** (wider support). Building the package still requires a **Swift 6** toolchain (`swift-tools-version: 6.0`).

## Migration steps

1. Bump the SPM dependency to `0.1.1` (or `from: "0.1.1"`).
2. If your app’s deployment target was raised only for this SDK, you may lower it to iOS 15.0+.
3. No API renames in this release.

## New permissions / privacy

None — same empty Privacy Manifest / no usage strings as v0.1.0.

## Verification

- [ ] Sample or host app builds against `v0.1.1`
- [ ] `swift test` / GitHub Actions `iOS` workflow green
- [ ] Smoke on an iOS 15+ simulator or device
