# Integration guide — v0.1.0

Baseline public surface for the first tagged SDK release.

## Who should read this

Host apps integrating Diverge SDK for the first time on iOS (SPM) or Android (local Maven module / future Central).

## Public API

### Configure once at launch

**iOS**

```swift
import DivergeSDK

try Diverge.configure(
    Configuration(apiKey: "sk_sandbox_...", environment: .sandbox)
)
let client = try Diverge.shared
print(client.apiBaseURL) // https://sandbox.api.askdiverge.ai
```

**Android**

```kotlin
import ai.askdiverge.sdk.Configuration
import ai.askdiverge.sdk.Diverge
import ai.askdiverge.sdk.Environment

Diverge.configure(
    Configuration(apiKey = "sk_sandbox_...", environment = Environment.SANDBOX)
)
val client = Diverge.shared
```

### Environments

| Environment | iOS | Android | API base URL |
|-------------|-----|---------|--------------|
| Sandbox | `.sandbox` (`sandbox`) | `Environment.SANDBOX` (`wireName = sandbox`) | `https://sandbox.api.askdiverge.ai` |
| Production | `.production` (`production`) | `Environment.PRODUCTION` (`wireName = production`) | `https://api.askdiverge.ai` |

No live network calls are made by `configure` in v0.1.0; URLs are resolved for future API work.

## Breaking changes

None — this is the initial public surface.

## Migration steps

1. Add the package / module dependency.
2. Call `configure` before reading `shared`.
3. Use sandbox keys in development; never commit production secrets.

## New permissions / privacy

- Info.plist: none required for v0.1.0 SDK features
- Privacy Manifest: empty accessed-API arrays (see `Sources/DivergeSDK/PrivacyInfo.xcprivacy`)
- ATT: SDK does not request tracking — see `Docs/site/att.html`
