# Integration guide — v0.1.0

Baseline public surface for the first tagged **iOS** SDK release.

## Who should read this

Host apps integrating Diverge SDK for the first time via Swift Package Manager.

Android: see [Diverge-SDK-Android](https://github.com/askdiverge/Diverge-SDK-Android).

## Public API

### Configure once at launch

```swift
import DivergeSDK

try Diverge.configure(
    Configuration(apiKey: "sk_sandbox_...", environment: .sandbox)
)
let client = try Diverge.shared
print(client.apiBaseURL) // https://sandbox.api.askdiverge.ai
```

### Environments

| Environment | Raw value | API base URL |
|-------------|-----------|--------------|
| Sandbox | `sandbox` | `https://sandbox.api.askdiverge.ai` |
| Production | `production` | `https://api.askdiverge.ai` |

No live network calls are made by `configure` in v0.1.0; URLs are resolved for future API work.

## Breaking changes

None — this is the initial public surface.

## Migration steps

1. Add the SPM package dependency (prefer a SemVer pin / GitHub Release tag).
2. Call `configure` before reading `shared`.
3. Use sandbox keys in development; never commit production secrets.

## New permissions / privacy

- Info.plist: none required for v0.1.0 SDK features — see [`Docs/privacy/`](../privacy/)
- Privacy Manifest: empty accessed-API arrays (`Sources/DivergeSDK/PrivacyInfo.xcprivacy`)
- ATT: SDK does not request tracking — see [`Docs/site/att.html`](../site/att.html)
