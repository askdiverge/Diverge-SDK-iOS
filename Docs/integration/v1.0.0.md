# Integration guide — v1.0.0

First stable release of the **iOS** Diverge SDK: the conversational chat as a single SPM product,
`AIConversation`. From 1.0.0 on, `1.x.y` keeps the public API and wire contract stable; a breaking
change arrives only with a new major.

## Who should read this

- Host apps integrating the SDK for the first time.
- Host apps upgrading from `v0.1.0`, whose scaffold API (`Diverge`, `DivergeClient`,
  `DivergeSDKUI`) is removed.

Android: see [Diverge-SDK-Android](https://github.com/askdiverge/Diverge-SDK-Android).

## Requirements

- App deployment target **iOS 18.0+**.
- Swift 6 toolchain (`swift-tools-version: 6.0`) to build the package.
- A backend endpoint of your own that mints visitor session tokens (see step 2 below). The API key
  stays on your server and never ships in the app.

## Breaking changes

| Area | Before (`v0.1.0`) | After (`v1.0.0`) | Action |
|------|-------------------|------------------|--------|
| Products | `DivergeSDK` and `DivergeSDKUI` | `AIConversation` | Replace both products with `AIConversation`; `import AIConversation`. |
| Setup | `Diverge.configure(Configuration(apiKey:environment:))` | `AIChat(_:)` or `AIChat.configure(_:)` with `AIChat.Configuration` | Build the configuration from the hooks below. |
| Credentials | API key passed to the SDK in the app | `tokenProvider` returns a visitor session token minted by your backend | Move the API key to your backend and mint tokens there. |
| Environment | `Environment.sandbox` / `.production` | `DivergeAPI.Environment.development` / `.production` (default `.production`) | Pass `environment:` only for development builds. |
| Client | `DivergeClient`, `Diverge.shared`, `isConfigured`, `reset()`, `version`, `apiBaseURL` | The `AIChat` instance owns the session | Keep the `AIChat` instance for as long as the session should live. |
| Errors | `DivergeError` | Shown inside the chat UI | Remove `DivergeError` handling. |
| UI | `DivergeStatusView` | `makeView()` (SwiftUI) / `makeViewController()` (UIKit) | Present the chat; your app owns presentation and dismissal. |

## Migration steps

1. **Swap the package product.** Pin `from: "1.0.0"` and depend on `AIConversation`:

   ```swift
   .package(url: "https://github.com/askdiverge/Diverge-SDK-iOS.git", from: "1.0.0")
   ```

2. **Mint visitor tokens on your backend.** Your server calls the Chatbot API's visitor auth with
   your API key and returns the visitor bearer token to the app. Endpoints and payloads:
   [Visitor Auth](https://docs.askdiverge.ai/api#tag/visitor-auth) and
   [Visitor Privacy](https://docs.askdiverge.ai/api#tag/visitor-privacy).

3. **Configure the chat.** The three hooks are required:

   ```swift
   import AIConversation

   let chat = AIChat(
       .init(
           tokenProvider: { try await myAuth.sessionToken() },
           resetConversation: { try await myAuth.newSessionToken() },
           deleteData: { try await myAuth.deleteVisitorData() }
       )
   )
   ```

   Or register it once at launch with `AIChat.configure(_:)` and create instances with `AIChat()`.

4. **Present it.**

   ```swift
   chat.makeView()                                    // SwiftUI
   present(chat.makeViewController(), animated: true) // UIKit
   ```

5. **Remove** every use of `Diverge`, `DivergeClient`, `Configuration(apiKey:)`, `DivergeError` and
   `DivergeStatusView`.

## Configuration

| Parameter | Required | Purpose |
|-----------|----------|---------|
| `tokenProvider` | yes | Returns a visitor session token on demand. The SDK never mints or stores credentials. |
| `resetConversation` | yes | Ends the conversation and returns a fresh session token. |
| `deleteData` | yes | Ends the session and wipes the visitor's data. |
| `contextProvider` | no | Resolved on every send; describes what the user is looking at (product, category, screen) so replies can target it. Non-identifying context only. |
| `onOpenLink` | no | Receives links tapped in a reply so your app can route them. Without it, links open in the browser. |
| `conversationFlow` | no | `.topDown` (default) lifts the sent message to the top and streams the reply beneath it; `.bottomUp` is a classic chat. iOS only. |
| `environment` | no | `.production` (default) or `.development` for integrating ahead of a backend release. |

## What the SDK sends

Every authenticated call carries `X-Diverge-SDK-Platform: ios`, `X-Diverge-SDK-Version: 1.0.0` and
`X-Diverge-Client-Profile`. Font and attachment downloads carry none of them. No host action is
needed.

## New permissions / privacy

- Info.plist: none required — see [`Docs/privacy/`](../privacy/).
- Privacy Manifest: `Sources/AIConversation/PrivacyInfo.xcprivacy` declares no tracking and no
  required-reason API use. It declares `OtherUserContent` as collected and linked, for app
  functionality: typed messages and the optional context string are sent to the assistant backend
  to generate replies.
- The SDK caches the chatbot's font under `Caches/`, keyed by its content hash. One font is kept at
  a time. Session tokens and conversations are kept in memory only.
- ATT: the SDK does not request tracking — see [`Docs/site/att.html`](../site/att.html).
