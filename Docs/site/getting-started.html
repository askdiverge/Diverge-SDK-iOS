Diverge SDK

Getting started (iOS)

Install the SDK via Swift Package Manager, supply the session-token and data hooks, then present the chat.

SPM

dependencies: [
    .package(url: "https://github.com/askdiverge/Diverge-SDK-iOS.git", from: "0.1.0")
]
// Product: AIConversation

import AIConversation

let chat = AIChat(
    .init(
        tokenProvider: { try await myAuth.sessionToken() },
        resetConversation: { try await myAuth.newSessionToken() },
        deleteData: { try await myAuth.deleteVisitorData() }
    )
)

chat.makeView()                                    // SwiftUI
present(chat.makeViewController(), animated: true) // UIKit

The SDK renders the conversation only; the host owns presentation and dismissal.

Minimum app deployment target: iOS 18.0+. Prefer SemVer pins from GitHub Releases — do not track main. Version stays at 0.1.0 until the API is stable.

See the baseline guide: Docs/integration/v0.1.0.md.

Android SDK: Diverge-SDK-Android.
