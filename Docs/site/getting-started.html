Diverge SDK

Getting started (iOS)

Install the SDK via Swift Package Manager, configure a sandbox API key, then read the shared client.

SPM

dependencies: [
    .package(url: "https://github.com/askdiverge/Diverge-SDK-iOS.git", from: "0.1.0")
]
// Products: DivergeSDK (required), DivergeSDKUI (optional status UI)

import DivergeSDK

try Diverge.configure(
    DivergeConfiguration(apiKey: "sk_sandbox_demo", environment: .sandbox)
)
print(try Diverge.shared.apiBaseURL, Diverge.version)

Minimum app deployment target: iOS 18.0+. Prefer SemVer pins from GitHub Releases — do not track main. Version stays at 0.1.0 until the API is stable.

See the baseline guide: Docs/integration/v0.1.0.md.

Android SDK: Diverge-SDK-Android.
