Diverge SDK

App Tracking Transparency (ATT)

The host app owns the ATT consent prompt (ATTrackingManager.requestTrackingAuthorization). The Diverge SDK does not present that prompt.

Current SDK contract (v0.1)

BehaviorSDK?Notes
Requests ATT authorization No Host app only
Reads IDFA / advertising identifier No Not used by the current SDK surface
Uses AppTrackingTransparency framework No —
Requires NSUserTrackingUsageDescription No (for SDK alone) Add only if the host tracks users
Holds a host-supplied session token in memory Yes In-process, obtained via tokenProvider; not persisted, not tracking

If product later adds tracking

  1. Update this page and the Privacy Manifest with accurate domains / data types.
  2. Document that the host must show ATT before any IDFA access.
  3. Add NSUserTrackingUsageDescription guidance to the Info.plist template.
