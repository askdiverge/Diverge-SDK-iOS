## Already available to consumers

Text chat + live streaming replies, rich text, product cards (open CTA + optional add-to-cart via host `onAddToCart` or link-mode cart URL), suggestion cards (tap to send), start-prompt chips (tap to send before the first user turn), in-conversation `quick_replies` chips (latest bot turn), tables, assistant images and files (tap to open), visitor photo attach (photo library → pending chip → send), guided “upload a photo” prompt (`request_image_upload` marker), scroll-up to load older history, branded welcome/theme (light + dark from `/config`, host `appearance` lock; `rgb()`/`rgba()` CSS colours), reset conversation, privacy policy + download my data (`GET /export`) + delete data, in-chat promo banners (`GET /chat/banners`), first page of history, session-ended alert, tappable links, localised UI copy, muted `.system` turns.

**On `iOS_CS_Livechat_Contact_Form` (not this branch):** in-conversation contact / support-ticket / custom forms, conversation rating on close, livechat / human agent.
